# 全国农产品批发价格日报

从农业农村部「全国农产品批发市场价格信息系统」([pfsc.agri.cn](https://pfsc.agri.cn)) 获取当天公开数据，生成可筛选、可留存的 Excel 日报。一次运行即可查看价格涨跌、分类报价、价格指数和报送市场信息。

> **使用方式：**这是一个在本机运行的 Python 命令行工具，不是网页应用。生成的 Excel 文件保存在本机，可用 Excel 或兼容软件打开。

## 日报包含哪些内容

运行一条命令，自动抓取并汇总：

| 数据 | 说明 |
| --- | --- |
| 涨跌幅排行 TOP20 | 今日全国涨幅前 10 + 跌幅前 10 的品种（含今日/昨日均价、涨跌幅） |
| 分类品种批发价 | 蔬菜、果品、畜禽产品、水产品等分类下**每个品种**的今日报价统计（报价市场数、最低/最高/平均价） |
| 批发价格指数(日) | 近一个月的全国农产品批发价格 200 指数走势 |
| 分类价格指数 | 各大类今日指数 vs 昨日指数 |
| 今日报送市场 | 当天有多少家批发市场报送了价格 |

输出为一个多工作表的 Excel 文件，文件名带数据日期，例如：

```
农产品批发价格日报_2026-08-13.xlsx
```

## 环境准备

需要 Python 3.9+。第一次使用先安装依赖：

```powershell
# 1. 创建虚拟环境（把项目依赖和电脑里其他 Python 环境隔离开）
python -m venv .venv

# 2. 激活虚拟环境
.venv\Scripts\Activate.ps1

# 3. 安装依赖
pip install -r requirements.txt
```

## 怎么运行

```powershell
# 默认运行：抓蔬菜、果品、畜禽产品、水产品 4 个分类，生成当日 Excel
python main.py

# 只抓指定分类
python main.py --categories 蔬菜 果品

# 查看网站上都有哪些分类
python main.py --list-categories

# 自定义输出文件名
python main.py --output 我的报表.xlsx

# 快速模式：跳过逐品种报价（只生成排行/指数/市场名单，几秒完成）
python main.py --no-detail

# 忽略今天的本地缓存，全部品种重新抓一遍
python main.py --refresh
```

完整运行（默认 4 个分类、600+ 品种）首次约 4~6 分钟；**同一天再跑第二次
只需要几秒钟**——因为已经抓过的品种会读本地缓存（`cache/` 目录），不再请求网站。
数据每天更新一次，建议每天上午跑一次。

## 错误提示说明

工具对常见问题都有明确的中文提示，不会"静默失败"：

| 提示 | 含义 | 怎么处理 |
| --- | --- | --- |
| 抓取失败：请求 xxx 连续失败 3 次 | 连不上网站 | 检查网络，确认 pfsc.agri.cn 能打开 |
| 接口 xxx 返回业务错误 | 网站接口临时故障 | 稍等几分钟重试 |
| 网站限流，本轮有 N 个品种被拦截 | 访问太频繁被网站临时封禁 | **工具会自动停手、倒计时等待解封后继续**，不用管它；如果连续等三轮还没好，剩余品种会跳过，可用 `--refresh` 稍后补抓 |
| 品种报价抓取完成：…本次未抓到的品种 | 个别品种因网络/限流没抓到 | 不影响整体，其他品种照常生成；稍后跑 `python main.py --refresh` 可补 |
| 所有数据都没有抓到 | 网站整体不可用 | 检查网络后重试 |

## 限流与缓存（重要）

该网站有防爬虫限流：约 3 分钟内只容忍几百次请求，超了会封禁约 3 分钟。
本工具为此做了三重防护：

1. **放慢节奏**：并发 2 线程 + 每次请求间隔 0.9 秒（约每秒 1.7 个请求），贴着网站容忍度走；
2. **被限流就刹车**：一旦检测到封禁，立刻停止发送新请求，倒计时等待解封后自动续抓，最多自动等 3 轮；
3. **本地缓存**：每天抓到的结果存在 `cache/日期.json` 里，同一天再跑直接读缓存，几乎零请求。

## 技术说明（给想了解原理的人）

- **数据接口来源**：本项目使用的接口全部来自网站自身前端（Vue.js 应用）的
  JS 源码，属于网站公开使用的接口，不需要登录、不涉及任何账号密码。
- **AES 解密**：报价接口返回的数据是加密的（AES-CBC），密钥和 IV 规则就写在
  网站前端 JS 里（`decryptAes` 函数），本项目按相同规则解密后使用。
- **礼貌爬取**：低并发（2 线程）+ 请求间隔（0.9 秒）+ 失败自动重试 + 限流自动
  停手等待，对网站压力很小。
- **代码结构**（入口 / 核心逻辑 / 配置分离）：

| 文件 | 职责 |
| --- | --- |
| `main.py` | 命令行入口，流程编排 |
| `config.py` | 全部配置（接口地址、密钥、抓取范围、抓取节奏） |
| `fetcher.py` | 网络请求 + AES 解密 + 重试 + 限流检测 + 错误处理 |
| `parser.py` | 把接口返回的 JSON 解析成表格数据 |
| `report.py` | 生成带格式的 Excel 报表 |
| `cache.py` | 本地缓存（同一天重复运行不再请求网站） |
